# AGENTS.md — правила для ИИ-агентов в этом репозитории

Резюме в этом репозитории собирается агентами, поэтому правила для них лежат рядом с кодом.

- Все факты резюме берутся только из верифицируемых источников: публичный GitHub кандидата и локальный конфиг его агентного харнеса.

## Правила факт-чека (hook: pre-commit)

1. Каждое числовое утверждение («N проектов», «M скиллов», «K коммитов») должно быть проверяемо: репозиторий, файл, коммит, страница платформы.
2. Запрещено добавлять факты без источника. Не уверен — не пишешь.
3. Слабые места не прячем: блок «Честно» — обязательная часть досье.

## Как править резюме

1. Данные кандидата — в объект `DATA` в начале `<script>` в `index.html`.
2. Одна правка = один коммит. Стиль сообщений: `feat|fix|docs: суть` — коротко, по-деловому.
3. Каноны страницы, которые нельзя ломать:
   - один самодостаточный HTML-файл, ноль сетевых запросов в рантайме;
   - «Сразу к досье» доступна всегда — HR нельзя проиграть;
   - noscript-версия, print-стили, `prefers-reduced-motion` уважаются;
   - режим `#doc` / `?doc` открывает досье без харнес-сессии.
4. Перед пушем: открыть `index.html`, проверить консоль на ошибки.

## Коммуникация

- Проблемы сообщаем сразу, коротко, без ожидания ревью — как принято у работодателя.
- Сначала смотрим в логи (консоль, вывод сборки), потом строим догадки.
