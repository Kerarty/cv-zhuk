# Резюме-харнес — интерактивное досье для «Python-разработчик (ИИ-агенты)»

**Смотреть:** [kerarty.github.io/cv-zhuk](https://kerarty.github.io/cv-zhuk/) ·
без ожидания — [сразу к досье](https://kerarty.github.io/cv-zhuk/?doc).

Отклик на вакансию **Python-разработчик (работа с ИИ-агентами)**, ИП Жук
([rabota.by/vacancy/139562400](https://rabota.by/vacancy/139562400?hhtmFrom=vacancy_search_list)).

## Зачем

Вакансия просит не резюме, а ссылку на работающий проект + пару предложений о работе
с агентами. Поэтому резюме собрано как демонстрация именно этих навыков: страница —
это **сессия харнеса**, в которой агент собирает досье у HR на глазах (стриминг задач,
хук факт-чека, субагенты resume-writer и reviewer). Форма отвечает содержанию.

## Что внутри

- **Харнес-сессия** — при загрузке агент «собирает» отклик: правила AGENTS.md →
  pre-commit факт-чек → субагенты → ревью. Кнопка «сразу к досье» доступна всегда,
  Esc пропускает сборку; повторное посещение открывает досье сразу.
- **$ лог опыта** — карьера как коммит-лог: БГУИР, 20 играбельных резюме за 6 недель,
  Проходная к публикации на трёх площадках, Python-клиент для QA-стенда SoftFx.
- **Проекты** — 6 карточек с проверяемыми метриками и ссылками на репозитории.
- **Харнес** — готовый абзац для отклика (кнопка «скопировать»), 49 субагентов,
  107 скиллов, правила конвейера.
- **Под вакансию** — честный маппинг требований на доказательства: ✓ есть /
  ◐ частично / ○ план 30-60-90.
- **Честно** — чего пока нет: коммерческого опыта, FastAPI в бою, боевого MySQL.
- **План 30-60-90** — первые три месяца в роли.
- **Fallback** — noscript-версия (все секции открыты), `#doc`/`?doc` без сессии,
  print-стили, `prefers-reduced-motion`.

## Каноны (как в предыдущих резюме-проектах)

- один самодостаточный HTML-файл, ноль сетевых запросов в рантайме;
- HR нельзя проиграть: skip-режим и прямые ссылки на любую вкладку (`#log`, `#projects`, `#harness`, `#fit`, `#honest`, `#plan`, `#contact`);
- все числовые факты проверяемы — источники: [github.com/Kerarty](https://github.com/Kerarty) и конфиг харнеса.

## Запуск

```bash
# открыть index.html двойным кликом — уже работает
# или поднять локальный сервер:
python -m http.server 8000
```
